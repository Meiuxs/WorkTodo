# WorkTodo V1.0 测试矩阵

运行环境：Node.js 24.19.0、Microsoft Edge 153.0.4234.32、Playwright 1.55.0

## 单元测试

| 规格区域 | 主要断言 | 测试位置 |
| --- | --- | --- |
| MV3 与权限 | manifest v3、仅 storage、无 host permissions | `tests/smoke.test.js` |
| 日期与状态 | 本地日期、时间对校验、逾期条件、非法日期 | `tests/domain/dates.test.js` |
| 任务领域 | 标题、描述、星标、状态迁移、首次计划日期、回收站 | `tests/domain/task.test.js` |
| ID 与事件 | UUID 生成、事件必填字段和 detail 快照 | `tests/domain/ids.test.js`、`tests/domain/task.test.js` |
| IndexedDB 迁移 | 新建 store、修复缺失索引 | `tests/data/database.test.js` |
| 仓库合约 | revision 冲突、原子更新、独立快照、设置隔离 | `tests/services/repository-contract.test.js` |
| 任务服务 | 创建、编辑、开始、完成、取消、恢复、延期、复制、分类迁移 | `tests/services/task-service.test.js` |
| 查询与搜索 | 今日排序、收集箱、逾期、完成、本地完成日期筛选 | `tests/services/task-query-service.test.js` |
| 统计 | 按 completedAt、创建、延期、取消、周聚合、完成率 | `tests/services/statistics-service.test.js` |
| 备份与导入 | 版本校验、冲突预览、merge、replace、失败回滚 | `tests/services/backup-service.test.js` |
| Popup 控制器 | 快速创建、关注任务上限、变更广播 | `tests/services/popup-controller.test.js` |
| Dashboard 控制器 | 路由、刷新、任务动作、导入状态 | `tests/services/dashboard-controller.test.js` |
| 任务行格式 | 状态与摘要不重复、进行中保留时间、完成时间 | `tests/services/dashboard-task-list.test.js` |
| 性能场景 | 10,000 条任务查询、搜索、统计、导出不修改快照 | `tests/services/performance-scenarios.test.js` |

## Chromium E2E

| 用户闭环 | 浏览器断言 | 测试位置 |
| --- | --- | --- |
| Popup 到 Dashboard | 快速新增、收集箱可见、刷新持久化 | `tests/e2e/popup-dashboard.spec.js` |
