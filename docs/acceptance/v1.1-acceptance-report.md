## 可靠性与数据验收

- IndexedDB 保存任务、标签、子任务关系、事件、搜索索引和重复模板。
- `chrome.storage.local` 仅保存设置和轻量元数据。
- 任务 `revision` 检测并发编辑冲突，避免静默覆盖。
- 重复任务使用 `occurrenceKey` 唯一约束，竞态下不会生成重复实例。
- 导入支持校验、预览、合并和覆盖；覆盖前保留恢复点。
- 数据库升级会补齐 V1.1 关系字段与索引。
- 浏览器重启后任务数据保持可读。

## 无障碍、兼容性与安全验收

- 核心操作支持键盘、可见焦点和 Esc 关闭编辑器。
- 任务状态、标签和逾期状态有文字或辅助语义，不依赖颜色单独表达。
- 390px 移动视口无横向溢出。
- 使用 Manifest V3，权限仅为 `storage`，无 host permissions。
- 运行时无服务器、CDN、第三方网络 API 或网页内容读取。
- E2E 网络监听未发现外部请求。
