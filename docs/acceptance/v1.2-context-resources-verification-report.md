# WorkTodo v1.2 资料上下文能力验收报告

## 结论

已完成 PRD 中“任务上下文资料”的 v1.2 实现，核心流程可用，回归测试全部通过，可作为浏览器扩展导入包发布。

## 已验收范围

- 资料类型：网页链接、文本片段、本地文件元数据/引用。
- 资料收集箱：资料可以独立创建、搜索、按类型筛选、关联任务和删除。
- 任务上下文：任务编辑器可添加资料、查看资料数量、解除关联；任务列表显示“资料 N”。
- 文件副本：可选保存本地副本，单文件上限 20 MB；副本 Blob 与资料列表元数据分离存储。
- 文件引用：支持重新选择文件进行重新关联，并可下载已保存副本。
- 数据备份：JSON 备份包含资料元数据、任务关联和文件副本省略警告，不把 Blob 直接塞入 JSON。
- 数据迁移：IndexedDB schema 从 v3 升级到 v4，新增 `resources`、`taskResources`、`resourceBlobs`。
- 离线与权限：仅保留 `storage` 权限；不读取网页内容、浏览历史、Cookie、剪贴板或网络资源。
- 可访问性与响应式：资料入口、筛选、关联和删除流程保留键盘操作与文本状态表达；已有 390px 视口回归通过。

## 发布信息

- 扩展版本：1.2.0。
- 浏览器导入方式：解压发布包后，在 Chromium 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，指向包内根目录。

## 已知边界

- v1.2 不自动读取当前网页内容，网页资料需要用户手动填写 URL；这是权限和隐私边界的一部分。
- JSON 备份不携带文件二进制内容，只携带文件元数据并报告遗漏的副本；跨设备恢复后需要重新选择文件。
