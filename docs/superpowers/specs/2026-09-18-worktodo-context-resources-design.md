# WorkTodo 资料上下文与任务关联 PRD

## 1. 文档信息

- 产品：WorkTodo
- 版本目标：v1.2
- 文档类型：产品需求与交互设计
- 日期：2026-09-18
- 状态：待用户审阅

## 2. 背景与问题

WorkTodo 当前能够记录任务标题、描述、计划日期、优先级、标签、子任务和重复规则，但任务上下文仍主要依赖用户手动记忆。真实工作中的待办通常还依赖一份网页、一份本地文件或一段会议资料。

如果用户只能把这些内容混在描述里，会产生三个问题：

1. 下一步动作和参考资料混在一起，打开任务后仍不知道先做什么。
2. 同一份资料被多个任务使用时必须重复粘贴，修改链接或说明也容易不一致。
3. 工作回顾只能看到任务标题，看不到完成任务时依赖的上下文。

本版本为任务增加一个轻量的“资料上下文层”，让用户能够在不离开离线工作台的情况下记录、复用和回看相关资料。

## 3. 目标用户与目标

目标用户是受限办公环境中的单人知识工作者，包括工程技术、项目、销售和行政人员。

本版本目标：

- 用户可以在 10 秒内给任务添加一个网页链接、文件资料或文本片段。
- 用户可以先把资料放入资料收集箱，稍后再关联任务。
- 同一份资料可以被多个任务复用。
- 资料可以按标题、URL、文件名和文本片段内容搜索。
- 所有资料仍然本地可用，扩展不读取当前网页、不读取浏览历史、不读取剪贴板。
- 资料不会破坏“三秒记录”和“今天一眼看清”：今日页默认不展开资料详情。

## 4. 非目标与边界

本版本明确不做：

- 自动读取当前浏览器页面标题、URL 或网页正文。
- 通过剪贴板 API 自动读取用户剪贴板。
- 网页正文抓取、网页离线快照或全文知识库。
- 多人共享、云端同步、登录和服务器存储。
- 自动解析 PDF、Office、图片或音视频内容。
- 完整文件管理器、文件夹树或版本管理。
- 通过新增 host permissions 访问任意网站。

浏览器不会向扩展可靠暴露用户电脑的完整绝对文件路径，因此文件引用只保存用户主动选择时可获得的文件元数据；不能把“路径”承诺为跨设备稳定地址。

## 5. 核心用户旅程

### 5.1 从任务添加资料

1. 用户打开任务编辑器。
2. 默认仍只看到标题、计划日期和现有核心字段。
3. 用户展开“相关资料”。
4. 选择“网页链接 / 本地文件 / 文本片段”。
5. 用户填写或选择内容，确认保存。
6. 任务显示“相关资料 N”，但列表页和今日页只显示数量，不展开长 URL 或正文。

### 5.2 资料先进入收集箱

1. 用户打开“资料收集箱”。
2. 点击“添加资料”。
3. 选择类型并录入资料。
4. 资料保存为未关联状态。
5. 用户可以稍后选择一个或多个任务进行关联。
6. 关联后仍保留在资料库中，支持再次复用。

### 5.3 从任务中复用已有资料

1. 用户在“相关资料”中点击“关联已有资料”。
2. 搜索资料名称、URL、文件名或片段内容。
3. 选择一条或多条资料。
4. 资料出现在任务上下文中，不复制底层资料实体。

### 5.4 完成后回看

工作记录中的完成明细可按需展开资料摘要，默认只显示资料数量。用户打开已完成任务后，可以看到当时关联的资料，帮助复盘“完成了什么、参考了什么”。

## 6. 资料类型与保存规则

### 6.1 网页链接

字段：

- `type`: `url`
- `title`: 用户填写或从 URL 推导的显示名称
- `url`: 仅接受 `http://` 或 `https://`
- `note`: 可选说明，最多 2,000 字符

扩展只保存用户输入的 URL，不发起网络请求，不读取网页标题，不验证链接是否可访问。

### 6.2 本地文件

字段：

- `type`: `file`
- `title`: 默认使用文件名，用户可修改
- `fileName`
- `mimeType`
- `size`
- `lastModified`
- `storageMode`: `reference` 或 `copy`
- `blob`: 仅 `storageMode=copy` 时保存
- `note`: 可选说明，最多 2,000 字符

默认模式为 `reference`：保存文件元数据，不保存文件内容。用户可以主动选择“保存一份副本”，切换为 `copy`。

v1.2 文件副本限制：单个文件最大 20 MB；超过限制时不保存副本，但仍允许保存元数据引用。文件副本不支持自动解析和全文搜索。

文件引用失效时，用户可以重新选择文件并更新资料；系统不把旧文件静默替换为新文件。

### 6.3 文本片段

字段：

- `type`: `snippet`
- `title`: 必填
- `content`: 必填，最多 20,000 字符
- `note`: 可选说明，最多 2,000 字符

文本只能通过用户主动输入或粘贴到扩展输入框中获得。扩展不调用剪贴板读取 API。

## 7. 数据模型

新增 `resources` 对象仓库：

```text
Resource {
  id: string
  type: 'url' | 'file' | 'snippet'
  title: string
  note: string
  url: string | null
  fileName: string | null
  mimeType: string | null
  size: number | null
  lastModified: number | null
  storageMode: 'reference' | 'copy' | null
  blob: Blob | null
  content: string | null
  createdAt: string
  updatedAt: string
  revision: number
}
```

新增 `taskResources` 对象仓库：

```text
TaskResource {
  taskId: string
  resourceId: string
  position: number
  createdAt: string
}
```

资料收集箱通过没有任何 `taskResources` 关联的资源表达，不额外创建第二份资料实体。

任务删除或进入回收站不会自动删除资料实体；解除最后一个任务关联后，资料仍保留在资料收集箱，避免误删用户资料。

## 8. 界面与交互要求

### 8.1 任务编辑器

- 增加可折叠的“相关资料”区块。
- 默认收起，标题旁显示已关联数量。
- 提供“添加资料”和“关联已有资料”。
- 每项资料显示类型图标的文字替代、标题和简短来源。
- URL 长文本截断显示，但完整 URL 可通过详情或复制获得。
- 删除关联只解除关系，不删除资料实体。

### 8.2 资料收集箱

- 增加独立路由“资料收集箱”。
- 默认按最近更新倒序。
- 支持按类型筛选和关键词搜索。
- 未关联资料显示“未关联任务”状态。
- 提供“关联任务”“编辑资料”“删除资料”操作。
- 删除保存副本前必须显示文件大小和后果说明，并提供取消入口。

### 8.3 快速入口

- Popup 不增加复杂资料表单，保留“三秒记录”优先。
- Popup 只增加一个低干扰入口“打开工作台添加资料”。
- Dashboard 快速新增任务成功后，可继续进入任务详情补充资料，但不强制用户填写。

## 9. 搜索、导入与导出

- 任务搜索保留现有标题和描述搜索。
- 资料收集箱搜索覆盖 `title`、`url`、`fileName`、`content`、`note`。
- 任务搜索结果可通过“有资料”筛选，但不默认把资料全文混入任务结果排序。
- JSON 备份包含资料元数据、URL、文本片段和任务关联。
- JSON 备份默认不包含本地文件 Blob，导入后显示“副本未随备份导出，需要重新选择文件”。
- 导出前明确说明文件副本不会包含在 JSON 中，避免用户误以为备份完整。
- 导入校验必须拒绝无效资源类型、超限文本、非法 URL、孤儿任务关联和重复关系。

## 10. 隐私、安全与权限

- 不新增 host permissions。
- 不读取网页、历史、Cookie、密码或系统剪贴板。
- 文件只能通过用户主动选择的 file input 进入扩展。
- 文件副本写入 IndexedDB，不上传、不访问外部服务。
- URL 只作为字符串保存，不自动请求。
- 所有资料状态均提供文字说明，不依赖颜色单独表达。

## 11. 性能与兼容性

- 目标 Chromium 110+、统信 UOS、ARM64。
- 资料列表必须按索引读取，不在每次搜索时全表扫描任务与资料 Blob。
- Blob 不参与全文搜索索引。
- 任务列表不加载文件 Blob，只加载元数据；只有用户打开副本时才读取 Blob。
- 10,000 条任务和 5,000 条资料下，今日页、资料收集箱和关键词搜索不得出现明显无响应。

## 12. 验收标准

1. 三种资料类型都能创建、编辑、查看和删除。
2. 资料可先进入收集箱，再关联一个或多个任务。
3. 同一资料关联多个任务时只保存一个资料实体。
4. 解除任务关联不会删除资料实体。
5. 文件默认只保存元数据，用户明确选择后才保存副本。
6. 单个文件超过 20 MB 时不能保存副本，但可以保存引用元数据。
7. 资料搜索覆盖标题、URL、文件名、片段和备注。
8. JSON 导入导出包含资料元数据和关系，明确报告文件副本未导出。
9. 扩展权限仍只有现有必要权限，不新增 host、clipboard 或 history 权限。
10. Popup 快速新增流程不增加必填字段，不影响三秒记录。
11. 删除、解除关联和替换文件都有明确后果说明与取消路径。
12. 单元测试、端到端测试和响应式测试覆盖上述流程。

## 13. 分期建议
