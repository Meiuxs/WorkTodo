# WorkTodo V1.1 Data Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 V1.1 所需的 schema v2、标签数据、子任务关系字段和旧备份兼容层。

**Architecture:** 领域任务对象新增可选关系字段，IndexedDB v2 增加 tags 与 recurringTemplates store，任务仓库增加父子、系列和 occurrenceKey 查询能力。标签使用独立实体；备份 v1 导入时在内存中升级为 v2，再经过同一套校验和事务写入。

**Tech Stack:** 原生 ES Modules、IndexedDB、Node.js `node:test`。

**Spec:** `docs/superpowers/specs/2026-09-17-worktodo-v1.1.md`

**Depends on:** 当前 `feat/worktodo-v1.0` 分支的 V1.0 实现。

## Global Constraints

- `tagIds` 必须是字符串数组，`parentId`、`seriesId`、`occurrenceKey` 必须是字符串或 null。
- 子任务只允许一层：有 `parentId` 的任务不能再拥有子任务。
- 任务主数据、标签和事件存储在 IndexedDB；`chrome.storage.local` 只存设置和轻量元数据。
- schema 升级失败不得清空数据，必须保留旧数据并返回可诊断错误。
- 不新增权限，不读取网页、历史、密码、Cookie 或剪贴板。
- 日期继续使用 `YYYY-MM-DD`，时间戳继续使用含时区的 ISO 8601。
- 所有任务先写失败测试，再写最小实现；每个任务结束提交。

function normalizeTagIds(tagIds) {
  if (tagIds === undefined) return [];
  if (!Array.isArray(tagIds)) throw new ValidationError('tagIds 必须是数组');
  const normalized = tagIds.map((id) => {
    assertIdentifier(id, 'tagId');
    return id;

`src/domain/tag.js`：

```js
export function createTag({ name }, now, id) {
  if (typeof name !== 'string' || name.trim().length === 0) {
    throw new ValidationError('标签名称不能为空');
  }
  return { id, name: name.trim(), createdAt: now, updatedAt: now };
}
```

在 `tests/helpers/fakes.js` 增加内存版 `InMemoryTagRepository`，提供 `create/get/list/update/deleteAndDetach`，并用 `seedTask/getTask` 支持合约断言。

`TagRepository.deleteAndDetach(id, { updatedAt, createEvent })` 在同一个 IndexedDB transaction 中读取 `tasks` 与 `tags`，为每个引用它的任务写入 `tagIds.filter((tagId) => tagId !== id)`、`updatedAt`、递增值 revision 和 `EDIT` 事件，最后调用 `transaction.objectStore('tags').delete(id)`。任一写入失败时 transaction 自动回滚。

`src/services/tag-service.js`：

```js
export class TagService {
  #repository;
  #now;
  #generateId;

  constructor(repository, { now = () => new Date().toISOString(), generateId } = {}) {
    this.#repository = repository;
    this.#now = now;
    this.#generateId = generateId;
  }

  create(name) {
    return this.#repository.create(createTag({ name }, this.#now(), this.#generateId()));
  }

  list() {
    return this.#repository.list();
  }

  async rename(id, name) {
    const current = await this.#repository.get(id);
    if (current === undefined) throw new ValidationError(`标签 ${id} 不存在`);
    return this.#repository.update(createTag({ name }, current.createdAt, id));
  }

  deleteAndDetach(id) {
    const now = this.#now();
    return this.#repository.deleteAndDetach(id, {
      updatedAt: now,
      createEvent: (task) => createTaskEvent({
        id: this.#generateId(),
        taskId: task.id,
        type: 'EDIT',
        occurredAt: now,
        detail: { removedTagId: id },
      }),
    });
  }
}
```

```js
export class SubtaskService {
  async createSubtask(parentId, input) {
    const parent = await this.#taskService.getTask(parentId);
    if (parent.parentId !== null) throw new ValidationError('子任务不能再创建子任务');
    return this.#taskService.create({ ...input, parentId });
  }

  async activeCount(parentId) {
    return (await this.#repository.listChildren(parentId))
      .filter((task) => task.trashedAt === null && !['completed', 'cancelled'].includes(task.lifecycle))
      .length;
  }

  async completeParent(parentId, revision, { force = false } = {}) {
    if (!force && await this.activeCount(parentId) > 0) {
      throw new ValidationError('父任务仍有未完成子任务');
    }
    return this.#taskService.complete(parentId, revision);
  }
}
```

`TaskService.complete` 的签名保持不变；是否允许完成由 `SubtaskService.completeParent` 在调用前判断，避免把父任务 UI 策略塞进通用任务状态机。

const SCHEMA_VERSION = 2;

function upgradeBackup(backup) {
  if (backup.schemaVersion === 1) {
    return {
      ...backup,
      schemaVersion: 2,
      tasks: backup.tasks.map((task) => ({
        parentId: null,
        tagIds: [],
        seriesId: null,
        occurrenceKey: null,
        ...task,
      })),
      tags: [],
      recurringTemplates: [],
    };
  }
  return clone(backup);
}
